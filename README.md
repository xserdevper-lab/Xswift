# Xswift

แอปหน้าเดียวสำหรับรถยนต์ Suzuki Swift คันเดียว ใช้ GitHub Pages เป็นหน้าจอ, Google Sheets เก็บ snapshot รถและประวัติใบเสร็จแบบเพิ่มแถวใหม่ และ Google Drive เก็บรูปที่อัปโหลดจากแอป

## ข้อมูลในแอป

- รุ่นรถ ทะเบียน และราคา
- งบค่าน้ำมันและยอดเติมสะสม
- วันต่อภาษี วันหมดภาษี ประเภท/ปีประกัน และวันหมดประกัน
- วันหมดอายุใบขับขี่ วันเปลี่ยนแบตเตอรี่ และกำหนดเข้าศูนย์บำรุงรักษา
- บันทึกเกี่ยวกับรถ รูปรถ และรูปใบขับขี่
- อากาศบริเวณตำแหน่งปัจจุบัน พร้อมคำเตือนขับขี่เมื่อฝนตก

การ์ดอากาศขอสิทธิ์ตำแหน่งเมื่อผู้ใช้กด **Use current location** และเก็บพิกัดโดยประมาณไว้ใน local storage ของอุปกรณ์ เพื่ออัปเดตพยากรณ์เป็นระยะ พิกัดจะส่งให้ Open-Meteo เพื่อขอข้อมูลอากาศและไม่ส่งเข้า Google Sheets

## การเชื่อมต่อ

แอปไม่ต้องให้ผู้ใช้ลงชื่อเข้า Google แต่ใช้ Apps Script ที่ทำงานด้วยสิทธิ์ของเจ้าของชีต ก่อนใช้งานครั้งแรก เจ้าของต้องติดตั้ง backend ตาม [คู่มือ Apps Script](apps-script/README.md) และตั้ง URL ใน `config.js`

ผู้ใช้ปลดล็อกด้วย PIN ส่วนตัว 6 หลัก เซสชันจะอยู่ในแท็บนั้น 12 ชั่วโมง; เปิดแท็บใหม่ต้องกรอก PIN อีกครั้ง การอัปโหลดทำเมื่อผู้ใช้เลือกเองใน Settings ข้อมูลรถแต่ละครั้งจะเพิ่ม snapshot หนึ่งแถว ส่วนใบเสร็จเพิ่มเหตุการณ์เฉพาะรายการที่เปลี่ยนหรือถูกลบ โดยไม่เขียนทับข้อมูลเดิม ไฟล์รูปจริงอยู่ใน Drive และชีตเก็บรหัสรูป

## เริ่มใช้แอป

1. ตั้ง Apps Script และ deploy เป็น web app ตาม [apps-script/README.md](apps-script/README.md)
2. ใส่ URL ที่ลงท้ายด้วย `/exec` ใน `config.js`
3. เผยแพร่ `main` ผ่าน GitHub Pages
4. เปิด [Xswift](https://xserdevper-lab.github.io/Xswift/) แล้วกรอก PIN ส่วนตัวที่ได้จากขั้นตอนตั้ง backend

## ย้ายข้อมูลเดิมจาก XAMPP

ข้อมูลเดิมอยู่ใน localStorage ของ origin ที่เปิดแอปเก่า จึงไม่ปรากฏอัตโนมัติบน GitHub Pages:

1. เปิด `tools/export-legacy-car.html` ผ่าน XAMPP โดยใช้ host/port เดียวกับแอปเดิม
2. เปิด `http://localhost/<โฟลเดอร์แอป>/tools/export-legacy-car.html` แล้วดาวน์โหลด JSON
3. เปิด Xswift และเลือก **Import existing vehicle data**
4. ตรวจข้อมูลและยืนยันการนำเข้า

ไฟล์ส่งออกอาจมีข้อมูลส่วนตัวและรูปใบขับขี่ ควรเก็บไว้ในเครื่อง

## โครงสร้าง

- `index.html`: แอปหน้าเดียว/PWA
- `src/`: UI และ Apps Script API client
- `apps-script/`: backend ที่อ่าน/เขียนชีตและจัดการรูปภาพ
- `config.js`: Apps Script URL สาธารณะและ Spreadsheet ID
- `docs/deployment.md`: คู่มือเผยแพร่
