# Xswift — รถของฉัน

แอปหน้าเดียวสำหรับดูและแก้ไขข้อมูลรถยนต์หนึ่งคัน โดยใช้ Google Sheets เก็บข้อมูล และ Google Drive เก็บรูปรถ/ใบขับขี่ เข้าถึงได้หลังผู้ใช้ลงชื่อเข้าใช้ Google และบัญชีนั้นมีสิทธิ์แก้ไขชีต

## ข้อมูลในแอป

- รุ่นรถ ทะเบียน และราคา
- วันต่อภาษี วันสิ้นสุดภาษี ประเภท/ปีประกัน และวันสิ้นสุดประกัน
- วันหมดอายุใบขับขี่ และบันทึกเกี่ยวกับรถ
- รูปรถและรูปใบขับขี่ที่เก็บใน Drive

## เริ่มใช้งาน

1. ตั้งค่า Google Sheets API, Google Drive API และ OAuth Client ID ตาม [คู่มือติดตั้ง](docs/deployment.md)
2. ใส่ OAuth Client ID ใน `config.js` (Spreadsheet ID ตั้งไว้แล้ว)
3. ให้บัญชี Google ที่ลงชื่อเข้าใช้เป็น Editor ของสเปรดชีต
4. เปิดแอปผ่าน GitHub Pages หรือเว็บเซิร์ฟเวอร์ที่ใช้ HTTPS/localhost แล้วเลือก **เชื่อมต่อ Google**

เมื่อเชื่อมต่อครั้งแรก แอปจะสร้างแท็บ `รถยนต์` หากยังไม่มี โดยไม่แก้แท็บอื่น รูปภาพจะถูกอัปโหลดเข้า Drive ของบัญชีที่เชื่อมต่อ

## ย้ายข้อมูลเดิมจาก XAMPP

ข้อมูลเดิมอยู่ใน localStorage ของ origin ที่เปิดแอปเก่า จึงไม่ปรากฏอัตโนมัติบน GitHub Pages:

1. เปิดไฟล์ `tools/export-legacy-car.html` ผ่าน XAMPP โดยใช้ `localhost` host/port เดียวกับแอปเดิม (หรือคัดลอกโฟลเดอร์ `tools` ไปยังโฟลเดอร์ XAMPP เดิม)
2. เปิด `http://localhost/<โฟลเดอร์แอป>/tools/export-legacy-car.html` (ใช้ host/port เดียวกับแอปเดิม) แล้วดาวน์โหลดไฟล์ JSON
3. เปิดแอปใหม่นี้ ลงชื่อเข้าใช้ Google แล้วเลือก **นำเข้าข้อมูลรถเดิม** และเลือกไฟล์ที่ดาวน์โหลด
4. ตรวจสอบและยืนยันก่อนเขียนข้อมูลลงชีต

ไฟล์ส่งออกมีข้อมูลรถและอาจมีรูปใบขับขี่ ควรเก็บไว้ในเครื่องและลบทิ้งหลังนำเข้าแล้ว

## โครงสร้าง

- `index.html`: หน้าแอปหน้าเดียว
- `src/`: UI, OAuth, Google Sheets, Google Drive และการซิงก์
- `config.js`: OAuth Client ID และ Spreadsheet ID ซึ่งเป็นค่าระบุสาธารณะ ไม่มี client secret
- `docs/deployment.md`: การตั้งค่า Google Cloud และ GitHub Pages

ไม่ต้อง build หรือใช้แพ็กเกจ npm
